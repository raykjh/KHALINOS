## Editing rules

- Trinity receives two minutes; Side-scroll and Browser receive 25 seconds each including their results.
- Record each real execution chronologically. The final edit may remove loading and unchanged Cloud waiting.
- Every wait cut must preserve one execution ID before and after and display the matching **WAIT TIME REMOVED** label.
- Every profile change must introduce a visibly different **NEW … EXECUTION ID**.
- Keep Trinity intake screens readable for five to seven seconds. Side-scroll and Browser may move faster because the workflow is already explained.
- Use hard cuts for removed waiting. Use only short 4–6 frame dissolves between different surfaces.
- Do not show typing, account menus, unrelated windows, an unmoving game frame, or unsupported Godot modification claims.
- Do not call the verifier an external audit, the games commercially polished, or KHALINOS a universal autonomous builder.
